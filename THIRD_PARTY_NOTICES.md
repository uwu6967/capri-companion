# Attribution and private snapshot scope

This is a private development backup of an installed, customized Project Capricorn setup. It contains modified upstream Capricorn scripts and configuration as well as newly written companion/QoL code. Copyright in pre-existing mod code and artwork remains with its original authors; no blanket license is granted over this snapshot.

The original Project Capricorn mod is a required dependency. Upstream reference recorded during development: <https://www.nexusmods.com/cyberpunk2077/mods/36701>.

The green portrait is a generated color/style variant based on the original reference artwork. The green aura archive derives its effect structure from the installed game's native Blackwall upload effect. The original Capricorn archive and complete game assets are not bundled.

Cyber Engine Tweaks, redscript, TweakXL, ArchiveXL, Codeware, CyberwareEx and the game remain separate dependencies; their code and licenses are not replaced by this repository.

No repository-wide open-source license is asserted. Review upstream permissions before redistributing any derived materials publicly.
